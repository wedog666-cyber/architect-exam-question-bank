# 建築師考古題｜專注練習

這是一個無後端、可部署到 GitHub Pages 的建築師高考考古題練習站，已整理：

- 營建法規與實務：800 題
- 建築構造與施工：880 題
- 來源年度：104–114 年

## 手機使用說明

### 第一次使用：加入手機主畫面

- iPhone／iPad：用 Safari 開啟網站 → 點底部「分享」→「加入主畫面」→「新增」。
- Android：用 Chrome 開啟網站 → 點右上角「⋮」→「加到主畫面」或「安裝應用程式」。

加入後就能像 App 一樣從手機桌面開啟。網站不需要註冊，畫面會自動適應手機尺寸。

### 開始練習

1. 首頁選擇科目；若只想練特定法規，可再選「建築技術規則」等法規分類。
2. 選擇年度；不確定時可維持「不限年度」。
3. 選擇練習模式，再按綠色「開始練習」。
4. 點選 A、B、C 或 D，再按「下一題」。題號列可左右滑動並跳題。
5. 不確定的題目可按「標記這題」；最後一題按「交卷」。
6. 結果頁可看逐題檢討、單元表現，錯題會加入「錯題複習」。

### 交卷後的解析

答錯或未答的題目會自動展開選項對照；答對的題目也可點開檢討。標示「答案解析」的題目提供判斷理由、規範節次與來源連結；尚未核對理由的題目會明確顯示「詳細解析待補」。反向題會提醒應找錯誤敘述，答案修正採多重給分時也會另外說明。

目前已完成 11 題無障礙題目的來源解析（105–107 年），保存在 `docs/explanations.mjs`，重新產生題庫時不會覆蓋。這不是全題庫解析；新增內容須核對考試年度適用規定及 `acceptedAnswers`，不能只用答案字母推測理由。

### 模式選擇

- 快速練習：10 題、不限時，適合零碎時間暖身。
- 均衡抽題：20 題，從目前篩選範圍按年度平均取樣。
- 年度模擬：80 題、120 分鐘，適合完整模擬考試。
- 錯題複習：只抽過去完成測驗時答錯或未答的題目。

題目含原卷圖示時，點「原卷第 X 頁」查看；手機橫放或在圖片內放大會比較容易閱讀。年度模擬時間到會顯示「超時」，不會自動交卷。

完整圖文說明也可開啟：[手機使用說明](docs/guide.html)。

成績、錯題與最近練習只保存在目前手機瀏覽器，不會上傳；清除瀏覽器網站資料後，紀錄也會消失。

## 本機預覽

瀏覽器直接以 `file://` 開啟時，部分瀏覽器會阻擋題庫 JSON；請在專案根目錄執行：

```powershell
python -m http.server 8000 --directory docs
```

接著開啟 <http://localhost:8000>。

## 重新產生題庫

RAR 已先解壓到 `tmp/pdfs/`。替換來源 PDF 後，可重新執行：

```powershell
python scripts/build_question_bank.py `
  --input-root tmp/pdfs `
  --output docs/data/questions.json `
  --assets-root docs/assets/pages `
  --pdftoppm pdftoppm
```

清理器會保留題目原文與來源頁面，答案修正 PDF 優先於標準答案 PDF；撤銷題依答案備註採多重給分。產生結果與清理報告位於 `docs/data/questions.json`。

營建法規題會依題幹明示的法規名稱建立分類標籤；「無障礙設施設計規範」另以無障礙設施、設備等高辨識度題幹用語補充分類。其餘無法明確判定的題目會歸入「其他相關法規」，避免只因選項中偶然出現法規名稱而錯分。

## GitHub Pages

在 repository 的 Pages 設定選擇 `Deploy from a branch`，分支選 `main`，資料夾選 `/docs`。網站所有資產使用相對路徑，適用於 repository 子路徑部署。
